# 2026-06-06 blackW 续训隔离实验结果记录

## 1. `Jun05_13-38-33_` 弱 action/smoothness 续训结果分析

实验目的：验证 `Jun04_21-53-59_` 的崩溃是否主要由较强 `action_rate/smoothness` 惩罚触发，而不是 `Jun03_21-57-11_` 父 checkpoint 本身不可续训。

配置追溯：

- `Jun05_13-38-33_` 从 `Jun03_21-57-11_` 继续训练；
- dirty diff 只改了 `action_rate` 和 `smoothness`：从 `action_rate = -0.1`、`smoothness = -0.02` 放松为 `action_rate = -0.05`、`smoothness = -0.01`；
- 其他关键 reward 为 `torques = -6.0e-4`、`wheel_obstacle_lift = 1.2`、`tracking_lin_vel_x = 1.5`、`tracking_lin_vel_y = 1.5`、`tracking_ang_vel = 1.25`、`progress = 1.0`；
- 该 run 发生在后续 terrain heading/yaw-rate 随机化改动之前，仍是全局 `heading_command = True`，因此 TensorBoard 中没有 `cmd_curr_yaw_range/cmd_curr_yaw_score`。

关键曲线：

- step 10500：`mean_reward` 约 56.1，`terrain_level` 约 6.13，`value_loss` 约 0.139；
- step 12000：`mean_reward` 约 56.9，`terrain_level` 约 6.08，`value_loss` 约 0.197；
- step 13000：`mean_reward` 约 44.2，`terrain_level` 约 5.53；
- step 14000：`mean_reward` 约 26.5，`terrain_level` 约 5.30；
- step 15000：`mean_reward` 约 32.8，`terrain_level` 约 5.16，`value_loss` 约 0.140；
- 全程 `value_loss` 最高约 14.84，末尾约 0.140；`Policy/mean_noise_std` 从约 0.35 升到约 0.44，没有出现 `Jun04_21-53-59_` 那种持续失控；
- `rew_smoothness` 末尾约 -0.179，远好于 `Jun04_21-53-59_` 末尾约 -2.89；
- 但后段 `rew_torques`、`rew_collision`、`rew_base_height` 明显恶化：末尾分别约 -0.904、-0.282、-0.320，弱于 `Jun04_21-57-42_` 的末尾表现。

判断：

- 该隔离实验基本验证：`Jun04_21-53-59_` 的灾难性崩溃主要与过强 `action_rate = -0.1`、`smoothness = -0.02` 有关；
- `Jun03_21-57-11_` 父 checkpoint 并非完全不可续训，放松 action/smoothness 后不会再出现 value loss、noise std、smoothness reward 同时爆炸的失稳形态；
- 但这条父线后段可用性仍不如 `Jun04_21-57-42_`，表现为 terrain level 从高点约 6.15 缓慢回落到 5.16，且碰撞、力矩和高度项变差；
- `Jun05_13-38-33_` 更像是“隔离实验成功，但不是最佳可用模型”。

可用 checkpoint 建议：

- 当前可用性优先级：`Jun04_21-57-42_` final > `Jun05_13-38-33_` `model_12000.pt` > `Jun05_13-38-33_` final；
- 若要从 `Jun05_13-38-33_` 取模型观察，优先看 `model_12000.pt` 左右，此时 `terrain_level` 仍约 6.08，reward 未明显下滑，value loss 正常；
- 不建议直接用 `Jun05_13-38-33_` final 作为部署候选，除非 play/sim2sim 发现后段某些行为反而更符合实际需求。
