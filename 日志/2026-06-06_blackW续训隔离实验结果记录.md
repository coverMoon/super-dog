## 1. `Jun05_13-38-33_` 弱 action/smoothness 续训结果分析

实验目的：验证 `Jun04_21-53-59_` 的崩溃是否主要由较强 `action_rate/smoothness` 惩罚触发，而不是 `Jun03_21-57-11_` 父 checkpoint 本身不可续训。

配置追溯：

- `Jun05_13-38-33_` 从 `Jun03_21-57-11_` 继续训练；
- dirty diff 只改了 `action_rate` 和 `smoothness`：从 `action_rate = -0.1`、`smoothness = -0.02` 放松为 `action_rate = -0.05`、`smoothness = -0.01`；
- 其他关键 reward 为 `torques = -6.0e-4`、`wheel_obstacle_lift = 1.2`、`tracking_lin_vel_x = 1.5`、`tracking_lin_vel_y = 1.5`、`tracking_ang_vel = 1.25`、`progress = 1.0`；
- 该 run 发生在后续 terrain heading/yaw-rate 随机化改动之前，仍是全局 `heading_command = True`，因此 TensorBoard 中没有 `cmd_curr_yaw_range/cmd_curr_yaw_score`。

关键曲线：

- step 10500：`mean_reward` 约 56.1，`terrain_level` 约 6.13，`value_loss` 约 0.139；
- step 12000：`mean_reward` 约 56.9，`terrain_level` 约 6.08，`value_loss` 约 0.197；
- step 13000：`mean_reward` 约 44.2，`terrain_level` 约 5.53；
- step 14000：`mean_reward` 约 26.5，`terrain_level` 约 5.30；

- 全程 `value_loss` 最高约 14.84，末尾约 0.140；`Policy/mean_noise_std` 从约 0.35 升到约 0.44，没有出现 `Jun04_21-53-59_` 那种持续失控；

判断：

- `Jun05_13-38-33_` 更像是“隔离实验成功，但不是最佳可用模型”。

可用 checkpoint 建议：

- 当前可用性优先级：`Jun04_21-57-42_` final > `Jun05_13-38-33_` `model_12000.pt` > `Jun05_13-38-33_` final；
- 若要从 `Jun05_13-38-33_` 取模型观察，优先看 `model_12000.pt` 左右，此时 `terrain_level` 仍约 6.08，reward 未明显下滑，value loss 正常；
- 不建议直接用 `Jun05_13-38-33_` final 作为部署候选，除非 play/sim2sim 发现后段某些行为反而更符合实际需求。

## 2. hip_default 动态降权、stand wheel 约束与越障空转惩罚

根据实机 sim2real 反馈，本次围绕三类 gap 做小范围 reward/config 调整：髋关节在 y/yaw 指令下变形后不易回中、stand 静止时轮子/机体存在慢漂，以及高墙/楼梯越障时轮子撞障碍后空转。

改动内容：

- hip_default 基础权重从 -0.6 增大到 -0.9，但按 abs(cmd_y) 与 abs(cmd_yaw) 连续降权；默认 y_ref=0.5、yaw_ref=1.0、两轴降权系数均为 0.35，最低缩放 0.5。含义是 stand/直行时加强髋部回中，横移和 yaw 时保留必要姿态自由度。
- stand gate 增加 yaw 条件：norm(cmd_xy) < 0.1 且 abs(cmd_yaw) < 0.1 才视为 stand，避免原地 yaw 被 stand 约束误伤。
- 新增 stand_wheel_action = -0.2，stand 下惩罚四个 wheel action，减少策略主动给轮子非零指令。
- 新增 stand_wheel_vel = -0.02，stand 下轻量惩罚 wheel dof velocity，用于压制静止空转，同时避免过强导致反向补偿/抖动。
- 新增 wheel_obstacle_spin = -0.03，只在楼梯上、楼梯下和高墙地形上生效；当前 gate 为轮子水平接触力超过 25N、前方障碍相对高度超过 0.035m、前进命令 cmd_x > 0.2、base 前向速度低于 0.25m/s，并惩罚超过 8rad/s 的 wheel 速度平方。
- wheel_obstacle_lift = 1.2 及其触发/目标逻辑保持不变，避免同时削弱越障抬轮能力。

预期观察：

- rew_hip_default 在 stand/直行下会更强，y/yaw 指令下不会全强度压制；实机重点看 y/yaw 后髋部是否更容易回中。
- TensorBoard 新增 rew_stand_wheel_action、rew_stand_wheel_vel，用于区分策略主动给 wheel action 与物理轮速漂移。
- TensorBoard 新增 rew_wheel_obstacle_spin，高墙/楼梯上应只在卡障碍高速空转时明显为负；同时关注 rew_wheel_obstacle_lift、terrain_level、rew_tracking_lin_vel_x 是否被误伤。

风险和回退：

- 若 y/yaw 能力明显下降，优先将 hip_default_cmd_min_scale 从 0.5 降到 0.4，或把 hip_default 从 -0.9 回退到 -0.8。
- 若 stand 下 wheel 约束导致原地 yaw 变差，先检查 yaw gate 是否命中；必要时放宽 stand_still_yaw_threshold 或降低 stand_wheel_action。
- 若越障能力下降，优先把 wheel_obstacle_spin 从 -0.03 降到 -0.015 或提高 spin_threshold，暂不改 wheel_obstacle_lift。

补充修正：

- 根据此前 black 点式足四足训练经验，原 stand_still reward 的移动判断不加入 yaw 指令，保持只按 norm(cmd_xy) < 0.1 判断，避免 yaw gate 影响原有 stand_still 学习稳定性。
- stand_still_yaw_threshold 仍保留，但只用于新增的 stand_wheel_action 与 stand_wheel_vel，目的是避免原地 yaw 指令时轮子 action/速度被静止轮子约束误伤。
