# 2026-06-25 blackW 楼梯/高墙分组实验开关记录

## 1. 上楼梯 Jun06 风格逻辑开关

为便于从 Jun06 模型继续训练并同时对照当前高墙/平地优势，本次不新增 reward 项，只给现有 `wheel_obstacle_lift` 和 `wheel_obstacle_spin` 加两个配置开关：

- `rewards.wheel_obstacle_lift.stairs_use_simple_lift`：默认 `False`。开启后仅在上楼梯 terrain type 3 中使用 Jun06 风格简化抬轮逻辑：目标高度为障碍高度加 clearance，active time 固定，target error 只罚未抬够，不使用高障碍额外目标/额外 active time/过抬惩罚。高墙 type 9 仍走当前复杂 lift 逻辑。
- `rewards.wheel_obstacle_spin.stairs_use_threshold_spin`：默认 `False`。开启后仅在上楼梯 terrain type 3 中使用 Jun06 风格硬阈值空转惩罚，其他地形继续使用当前连续滑差惩罚。

建议三组实验：A 组两个开关均关，作为当前逻辑基线；B 组只开启 `stairs_use_simple_lift`，隔离抬轮逻辑影响；C 组两个开关都开启，测试楼梯 lift/spin 同时回 Jun06 风格是否能保留 Jun06 上楼梯不前顶的优势。

观察重点：上楼梯前轮触台阶后 base/重心是否继续前挤、倾倒率、楼梯通过率、`rew_wheel_obstacle_lift`、`rew_wheel_obstacle_spin`、高墙通过姿态、平地速度跟踪和动作平滑。若 B 组已明显改善，优先保留 lift 解耦；若 C 组进一步改善，说明当前连续 spin 也在改变楼梯接触节奏。
