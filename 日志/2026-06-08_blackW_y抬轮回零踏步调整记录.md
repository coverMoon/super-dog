# 2026-06-08 blackW y 抬轮与回零踏步调整记录

## 1. Jun07_21-52-14_ sim2sim 反馈后的微调

背景：后续训练先沿用 Jun07_21-52-14_，该 run 从 Jun02_22-30-50_ 续训，在 sim2sim 中对横向 y 指令抬腿和姿态问题已有改善；相比 Jun07_21-54-19_，训练曲线也更稳定。

当前问题：

- y 指令下轮/腿抬得偏高，说明 wheel_lateral_clearance 的目标高度或 scale 偏强。
- 给较小 y 指令后再回零，有时策略会持续原地踏步，需要再给 x 或 yaw 指令才停止，推测与小 y 也触发完整抬轮奖励、动作模式残留有关。

本次改动：

- wheel_lateral_clearance 的 command_threshold 从 0.1 提到 0.18，新增 full_command_threshold = 0.45。
- _reward_wheel_lateral_clearance 从硬门控改为 y 指令幅值 ramp：abs(cmd_y) 低于 0.18 时不启用，0.18 到 0.45 之间线性增强，高于 0.45 后满强度。
- target_extra_height 从 0.04 降到 0.025，减少横向指令下过高抬腿。
- wheel_lateral_clearance scale 从 1.2 降到 0.7，保留横向离地趋势但降低诱导踏步和高抬腿的强度。

预期：

- 小 y 指令不再直接触发完整抬轮奖励，回零后 stand_still / stand_wheel 约束更容易把动作拉停。
- 中大 y 指令仍可获得抬轮奖励，但目标高度更低，减少过高抬腿。

观察重点：sim2sim 中小 y 回零是否仍持续原地踏步，y 指令下轮子是否从“过高抬腿”变为适度离地，同时关注 tracking_lin_vel_y、rew_wheel_lateral_clearance、rew_stand_wheel_action、terrain_level 和 value_loss。


## 2. x + yaw 混合指令转弯发硬调整

反馈：沿 Jun07_21-52-14_ 继续调参时，sim2sim 中同时给 x 和 yaw 会显得很硬，转不过弯。

判断：当前 run_still 只在 abs(cmd_x) > 0.1 且 abs(cmd_y) < 0.1 时启用，没有考虑 yaw 指令；因此 x + yaw 混合指令下，run_still = -0.5 仍会强压非轮关节回默认姿态，和转弯所需的腿部/髋部姿态调整冲突。

本次改动：

- 新增 run_still_yaw_threshold = 0.15。
- _reward_run_still 门控改为 abs(cmd_x) > run_still_x_threshold 且 abs(cmd_y) < run_still_y_threshold 且 abs(cmd_yaw) < run_still_yaw_threshold 时才启用。
预期：x 直行时仍保留 run_still 抑制持续运动关节变形；x + yaw 转弯时关闭 run_still，减少回中约束和转弯动作的冲突。hip_default_yaw_scale 暂不调整，避免同时改变髋默认姿态约束。观察 tracking_ang_vel、tracking_lin_vel_x、rew_run_still、rew_hip_default、姿态稳定性，以及实机/仿真中 x+yaw 是否更顺畅。


## 3. wheel_obstacle_lift 过高抬轮惩罚

问题：当前 wheel_obstacle_lift 在轮子达到 target_z 后，lift_progress 会保持 1，target_reward 也因 height_error clamp 到 0 而保持 1，因此超过目标高度不会变差，容易允许甚至间接鼓励持续高抬。

本次改动：

- target_reward 的高度误差从单边 clamp 改为 abs(target_z - wheel_z)，目标附近最高，低于或高于目标都会下降。
- 新增 over_lift_margin = 0.02、over_lift_sigma = 0.04、over_lift_penalty_weight = 0.5。
- 当 wheel_z 超过 target_z + 0.02m 后，按平方项扣分；超过越多扣得越明显，过高时 wheel_obstacle_lift 可以变成负收益。

预期：保留触障后的主动抬轮趋势，但抑制抬到目标后继续上抬或长时间高抬。观察 rew_wheel_obstacle_lift、越障通过率、base_height、torques，以及是否出现抬轮不足导致卡障。


## 4. wheel_lateral_clearance 双边高度误差

问题：wheel_lateral_clearance 原先使用 clamp(target_z - wheel_z, min=0)，轮子达到目标高度后继续上抬不会变差，因此可能继续鼓励或放任 y 指令下过高抬腿。

本次改动：

- 将 wheel_lateral_clearance 的高度误差改为 abs(target_z - wheel_z)。
- 目标高度附近奖励最高，低于目标和高于目标都会降低奖励。
- 不额外加入 over-lift penalty，先用双边 tracking_sigma 控制高度窗口。

预期：y 指令下轮子保持适度离地，而不是越高越不受约束。观察 rew_wheel_lateral_clearance、tracking_lin_vel_y、小 y 回零踏步和轮子实际离地高度。


## 5. 当前 A/B 对照实验参数归纳

本轮假设前述结构改动方向有效，直接围绕参数做 A/B 调参；回零踏步问题已在 sim2sim 中改善，因此后续重点放在 y 指令抬腿高度、越障抬轮不过高，以及 x + yaw 转弯发硬。

当前代码对应更强压高的一组参数：

- wheel_lateral_clearance = 0.45，target_extra_height = 0.015，tracking_sigma = 0.025；使用 y 指令 ramp 门控和双边高度误差，用于降低 y 指令下的轮子离地高度。
- wheel_obstacle_lift = 1.5，over_lift_margin = 0.015，over_lift_sigma = 0.035，over_lift_penalty_weight = 0.8；使用双边目标误差和过高抬轮惩罚，用于抑制越障时超过目标高度后继续上抬。
- run_still = -1.0，stand_still = -0.6，并新增 run_still_yaw_threshold = 0.15；x 直行时增强回中约束，x + yaw 时关闭 run_still，缓解转弯发硬。
- terrain_proportions 中楼梯上比例从 0.3 降到 0.2，高墙比例从 0.1 提到 0.2，用于增加高墙样本；wheel_obstacle_spin = -0.1，继续压制障碍前轮子空转。
- PPO 侧 entropy_coef = 0.0025，sym_coef = 1.0，尝试降低过多探索并加强左右对称。

对照实验建议保持从 Jun07_21-52-14_/model_10000.pt 出发，短训 1000-2000 iter 后先看 sim2sim。观察重点：y 指令下轮子实际离地高度、是否横蹭、tracking_lin_vel_y；高墙/楼梯上通过率、越障时是否卡轮或过高抬轮、rew_wheel_obstacle_lift；x + yaw 转弯顺畅度、tracking_ang_vel、rew_run_still、torques、base_height 和 value_loss。
