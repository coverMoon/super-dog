# 2026-06-11 blackW 落地冲击速度惩罚记录

## 1. 新增 foot_impact_vel 首触落地速度惩罚

针对近期训练后期出现 base_height、lin_vel_z、torques、collision 和 smoothness 同步恶化的问题，本次加入一个较保守的落地冲击速度惩罚。目标是减少轮/足从空中快速砸向地面或障碍后的姿态冲击，同时避免持续惩罚接触后的微小振动。

实现方式：在 base 环境中保存上一帧 feet_vel 为 prev_feet_vel，并增加 last_impact_contacts 接触历史；blackW reset 时清空 last_impact_contacts，并将 prev_feet_vel 置零，避免跨 episode 状态污染。blackW 新增 _reward_foot_impact_vel：当 feet_indices 的 z 向接触力首次超过 foot_impact_contact_force = 1.0 时，只惩罚上一帧向下速度超过 foot_impact_vel_threshold = 0.2m/s 的部分，返回平方和。

配置：foot_impact_vel scale 先设为 -0.02，小权重试探，避免策略因为害怕落地而削弱越障、贴边滚爬或高墙后的恢复动作。

预期观察指标：rew_foot_impact_vel、rew_lin_vel_z、rew_base_height、rew_torques、rew_collision、rew_smoothness、terrain_level、value_loss，以及 sim2sim 中高墙越过后的落地恢复是否更稳。

风险和回退：如果出现过墙后不敢下轮/下脚、落地恢复变慢、高墙通过率下降，优先将 foot_impact_vel scale 降到 -0.01 或直接置 0；如果惩罚几乎没有量级，可再考虑 threshold 从 0.2 降到 0.15，但不建议一开始放大权重。

## 2. 对角后腿误抬的轻量抑制方案备忘

现象：高墙场景中，前腿/前轮碰墙触发 wheel_obstacle_lift 后，交叉相对的后腿有时也会同步抬起，例如左前触墙时右后跟抬。这不是期望动作；理想行为是触墙轮局部处理障碍，非相关后腿不要过早离地。

暂不落实代码，先记录备选方案：

- 全局无水平力抑制：水平方向接触力低于阈值时，对超过 ground + wheel_radius + margin 的抬轮做轻惩罚。优点是简单，风险是压制 y/yaw、楼梯和乱石上的必要姿态调整，不建议作为第一版全局启用。
- 对角 pair 抑制：当前前轮触墙/处于 lift window 时，只轻罚其对角后轮的超额抬高，例如 FL 触墙时罚 RR，FR 触墙时罚 RL。这个更贴近问题本身，对 y/yaw 的伤害预计更小。
- 前轮触墙早期窗口抑制：只在前轮 lift 触发后的短时间内，例如 0.2-0.4s，轻罚对角后轮过早抬起；窗口后放开，避免阻碍后腿真正越障。当前看这是优先级最高的候选。
- 多轮同时抬起抑制：高墙接触上下文中，限制非接触轮同时明显抬高的数量或总量。优点是抑制全身一起乱抬，风险是影响必要的多腿协调。
- 姿态/对角高度差间接约束：通过 roll/pitch 或对角高度差间接抑制错误耦合。该方案更间接，容易和越障姿态冲突，暂不优先。

若后续实现，建议从“前轮触墙早期 + 对角后轮 + 很小权重”开始，且只在高墙/障碍接触上下文生效。观察重点：对角后腿是否还跟抬、高墙通过率、y/yaw tracking、rew_wheel_obstacle_lift、torques、collision、base_height 和 value_loss。

## 3. 暂时关闭 wheel_obstacle_lift 的 over-lift penalty

基于高墙过障中对角后腿误抬和近期后期不稳定现象，先将 wheel_obstacle_lift.over_lift_penalty_weight 从 0.5 置为 0.0，等价于关闭 over-lift penalty。保留 over_lift_margin / over_lift_sigma 字段和 reward 公式结构，便于后续只改配置即可恢复。

目标：减少 over-lift penalty 对必要抬轮/过墙姿态的压制，观察高墙尤其低速高墙是否更愿意完成轮心越障和后腿通过。

风险：关闭后可能重新出现抬轮过高、越墙后动作残留、torques 或 base_height / lin_vel_z 波动增加；也可能加重前腿触墙时的全身耦合抬腿。若这些现象明显，优先回退为 0.2-0.5 的小权重，而不是马上叠加强抑制项。

观察指标：rew_wheel_obstacle_lift、rew_foot_impact_vel、rew_torques、rew_collision、rew_base_height、rew_lin_vel_z、terrain_level、value_loss，以及 sim2sim 中高墙通过率和对角后腿是否过早跟抬。

## 4. action_scale 改为非轮关节逐关节配置

为后续单独调节髋/大腿/小腿 12 个非轮电机的动作幅度，将 blackW control.action_scale 从标量 0.25 展开为类似 stiffness / damping 的 dict 配置。当前 12 个非轮关节仍全部保持 0.25，训练行为目标上不改变，只打开后续逐关节调参能力。

实现方式：blackWEnv 初始化 dof 索引后生成 self.action_scale。若 cfg.control.action_scale 是 dict，则按 dof 名称匹配 12 个非轮关节，轮子不要求配置；若仍是标量，则保持旧行为。_compute_torques 中 position action 使用 self.action_scale，轮子速度控制仍由原始 wheel action 经 vel_scale / wheel_residual_scale 计算，不受逐关节 position scale 配置影响。

预期用途：后续可单独降低容易诱发错误抬腿或姿态耦合的关节 action_scale，或提高需要更主动越障的关节幅度。风险是逐关节 scale 不均会改变策略动作空间语义，修改后应从明确 checkpoint 分叉，并关注 tracking、torques、collision、base_height、lin_vel_z 与高墙动作协调。
