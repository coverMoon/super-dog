# 2026-06-16 blackW 高墙后腿跟抬对照结果记录

## 1. Jun15_23-02-42_ 与 Jun15_23-03-23_ 对照结论

本次复查 Jun15_23-02-42_ 和 Jun15_23-03-23_。两组都从同一阶段短续训到 29001，且配置中 `wheel_obstacle_rear_suppress = -0.08`、`action_rate = -0.08`、`dof_pos_limits = -0.1` 等关键 reward 保持一致；实际主要差异是 `train_cfg.algorithm.sym_coef`：Jun15_23-02-42_ 为 1.0，Jun15_23-03-23_ 为 0.5。

sim2sim 观察上，两组都能改善翻越高墙时后腿跟随抬起的问题，但 Jun15_23-02-42_ 的整体姿态更好。TensorBoard 末段曲线也支持继续保留 A 组路线：两组 mean_reward、terrain_level 接近，Jun15_23-02-42_ 的末段 `rew_smoothness` 更轻，最后 checkpoint 的 `rew_torques`、`rew_lin_vel_z`、`rew_base_height` 也略好；B 组降低 symmetry 后没有带来更明确的姿态收益。

因此当前将 `sym_coef` 从 0.5 回退到 1.0，保留高墙局部对角后轮误抬抑制项。后续建议以 Jun15_23-02-42_ 路线作为基准继续做小步对照；若还要验证 symmetry，可单独再跑 `sym_coef = 0.75`，不要同时改动 rear suppress 或 action/smoothness 权重。

## 2. Jun16_13-25-01_ action_rate 加重续训结果

复查 Jun16_13-25-01_。该 run 从 Jun15_23-02-42_ 继续续训到 30001，`sym_coef = 1.0`、`wheel_obstacle_rear_suppress = -0.08`、`dof_pos_limits = -0.1` 等保持不变，唯一主要行为差异是将 `action_rate` 从 -0.08 加重到 -0.085。

训练早段仍正常，约 29100 到 29200 时 mean_reward 在 62 到 65、terrain_level 接近 5.65；随后从约 29400 开始 `rew_smoothness`、`rew_torques`、`rew_dof_pos_limits` 同步恶化，29600 后 value loss 快速放大，末段 mean_reward 约 -28、mean_episode_length 约 802、terrain_level 约 5.05。末段 `rew_base_height`、`rew_lin_vel_z`、`rew_orientation` 和碰撞项也明显变差。

结论：在当前 A 组基准上继续加重 `action_rate` 到 -0.085 风险较高，会破坏姿态和价值学习稳定性；当前已回退到 -0.08。后续若还想改善动作平滑，建议不要直接继续加重全局 `action_rate`，可优先考虑更局部的触墙上下文约束，或用更小步长试 -0.0825 并只短训观察到 29400 附近。
