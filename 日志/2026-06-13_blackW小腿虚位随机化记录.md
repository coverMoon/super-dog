# 2026-06-13 blackW 小腿虚位随机化记录

## 1. A 档 calf backlash deadzone 随机化

背景：实机小腿关节不是电机直驱，平行四边形连杆与齿轮/连接件存在较明显虚位；同向持续运动啮合后响应尚可，主要风险来自虚位导致的小幅控制误差和换向初段空行程。完整方向迟滞模型暂不一次引入，先做 A 档保守压力测试。

实现：blackW 运行时识别 4 个 `calf_joint` 索引，并为每个 env、每条小腿在 reset 时采样 `calf_backlash_widths`。在 `_compute_torques` 的 P 控制路径中，仅对小腿 `pos_err` 做对称 deadzone：小于虚位宽度的部分不进入位置力矩，超过后只保留超出量；轮子速度控制、hip/thigh 位置控制和观测不受影响。

配置：新增 `domain_rand.randomize_calf_backlash = True`，`calf_backlash_range = [0.0, 0.035]` rad，约 0 到 2 度。该范围先偏保守，用于验证策略是否能适应小腿传动松旷；若实机虚位更明显，再考虑 `[0.01, 0.06]`。

预期观察：训练中重点看 `rew_tracking_lin_vel_x/y`、`rew_tracking_ang_vel`、`rew_base_height`、`rew_lin_vel_z`、`rew_torques`、`rew_smoothness`、`rew_collision`、`terrain_level` 和 `value_loss`。sim2sim/实机重点看小腿换向、落地、过墙后是否更稳，是否减少因小腿虚位导致的姿态抖动。

风险和回退：A 档 deadzone 不是方向相关 hysteresis，会在同向啮合后仍弱化小误差位置控制，因此可能让小腿显得偏软、落地支撑变差或促使策略加大动作幅度。如果出现 episode length 下降、smoothness/torques 明显恶化或越障退化，优先关闭 `randomize_calf_backlash` 或将范围降到 `[0.0, 0.02]`。若 A 档有效但仍不能解释实机换向空程，再实现 B 档方向迟滞 backlash。


## 2. B 档 calf backlash hysteresis 随机化

基于 `Jun13_14-45-32_` 的 A 档结果，`calf_backlash_range = [0.01, 0.08]` 和 `entropy_coef = 0.005` 从 `Jun12_22-25-45_` 20k 续训到 21k 未出现崩溃：末段 episode length 约 970，terrain level 约 5.3，value loss 正常。但 A 档的 `rew_smoothness`、`rew_action_rate` 和 `rew_torques` 较基线明显变差，说明对称 deadzone 会让小腿在同向啮合后仍显得偏软，策略需要用更大的动作变化吃掉虚位。

本次将 calf 虚位从 A 档对称 deadzone 改为 B 档方向迟滞 hysteresis。实现方式：保留每个 env、每条小腿随机采样的 `calf_backlash_widths`，新增 `calf_backlash_effective_targets`、`calf_backlash_last_targets`、`calf_backlash_remaining` 和 `calf_backlash_dirs`。当 calf target 同向变化时，若没有剩余空程则 effective target 正常跟随；当 target 方向反转时，先将 remaining 设为该关节采样虚位宽度，后续目标变化先消耗 remaining，超过剩余空程的部分才传递到 effective target。最终 P 控制使用 `effective_target - dof_pos` 作为小腿位置误差。

配置：新增 `calf_backlash_mode = "hysteresis"`，B1 范围先设为 `calf_backlash_range = [0.01, 0.06]` rad。保留 `"deadzone"` 兼容模式，便于回到 A 档对照。建议从 `Jun13_14-45-32_/model_21000.pt` 或 `model_21001.pt` 分叉续训，`entropy_coef` 继续用 0.005，不再额外加大。

预期观察：相比 A 档，理想现象是 `rew_smoothness`、`rew_action_rate`、`rew_torques` 有所回落，同时 `mean_episode_length` 维持 950+、terrain level 维持 5 左右、value loss 不抬升。sim2sim/实机重点看小腿换向初段是否更贴近真实空程，同向持续支撑是否比 A 档更硬、更少拍腿。

风险和回退：hysteresis 引入跨 step 状态，若出现小腿 target 与实际姿态长期偏置、落地支撑变慢、过墙后恢复滞后，优先将范围降到 `[0.005, 0.04]` 或切回 `calf_backlash_mode = "deadzone"` 做对照。若 B1 稳定且动作指标改善，再考虑将上限恢复到 0.08。


## 3. B2 play + Kp scale 小腿虚位模型

`Jun13_18-03-13_` 的 B 档 hysteresis 从 `Jun13_14-45-32_` 续训后明显失稳：约 21100 起 value loss 抬升，21200 后 tracking、base_height、lin_vel_z、torques 和 smoothness 持续恶化，末段 reward 转负。分析认为当前 hysteresis 过于激进：反向空程期间 effective target 冻结在旧啮合侧，但 P 控制仍以满 Kp 拉住旧目标，导致策略与旧侧目标对抗，并诱发高 torque / 高 smoothness penalty。

本次将默认 `calf_backlash_mode` 从 `"hysteresis"` 改为 `"play"`。play 模型不再每次反向强行设置一段硬冻结空程，而是约束 effective target 始终落在 `[motor_target - gap, motor_target + gap]` 窗口内；motor target 在窗口内小幅变化时 effective target 可以滞后，target 推到窗口边缘后 effective target 才随边界移动。同时新增 Kp 缩放：空程窗口中部只保留较小 calf 位置刚度，靠近窗口边缘时逐渐恢复完整刚度，避免空程状态下满力矩拉旧目标。

配置改为：`calf_backlash_mode = "play"`，`calf_backlash_range = [0.005, 0.02]`，`calf_backlash_min_kp_scale = 0.15`，`calf_backlash_engage_start = 0.6`，`calf_backlash_leak = 0.02`。保留 `"deadzone"` 与 `"hysteresis"` 分支，便于回退对照。

建议从 `Jun13_14-45-32_/model_21000.pt` 或 `model_21001.pt` 重新分叉，而不是从失稳的 `Jun13_18-03-13_` 继续。观察重点仍是 `mean_episode_length`、`terrain_level`、`value_loss`、`rew_torques`、`rew_smoothness`、`rew_action_rate`、`rew_base_height`、`rew_lin_vel_z`。若 B2 仍出现 value loss 快速抬升或 torque/smoothness 链式恶化，优先将 `calf_backlash_min_kp_scale` 提到 0.3 或将 range 降到 `[0.003, 0.015]`；若 B2 稳定但实机虚位覆盖不足，再逐步提高上限到 0.03。


## 4. 开启非轮关节 dof_pos_limits 小权重惩罚

检查 blackW URDF 后，hip/thigh/calf 均有正常有限关节范围；wheel_joint 使用 `[-999999, 999999]` 作为近似连续转动的假无限范围。base 版 `_reward_dof_pos_limits` 会对全部 DOF 求和，虽然轮子因假无限范围基本不会触发，但语义上轮子不应参与位置限位惩罚。

本次在 `BlackWEnv` 中覆盖 `_reward_dof_pos_limits`，只统计 `leg_dof_indices`，显式排除 `wheel_indices`。配置中将 `rewards.scales.dof_pos_limits` 从 `-0.0` 小幅打开为 `-0.2`，`soft_dof_pos_limit` 仍为 1.0，等价于仅在 hip/thigh/calf 真正越过 URDF 限位时惩罚，不提前收窄可用范围。

目标：防止引入 calf 虚位随机化后策略借小腿/大腿极限姿态补偿虚位，同时避免轮子连续转动被位置限位 reward 污染。

观察与回退：训练中关注 `rew_dof_pos_limits` 是否长期为 0 或只偶发非零，以及 `mean_episode_length`、`tracking`、`torques`、`smoothness`、`base_height` 是否受影响。如果该项频繁非零或导致越障退化，先降到 `-0.05` 或关闭，再定位具体是哪类腿关节越限。


补充：由于 `dof_pos_limits` 是对越过限位幅度的线性惩罚，而不是按次数惩罚，`-0.2` 对小幅越限约束偏弱；将权重提高到 `-0.5`，仍保持 `soft_dof_pos_limit = 1.0`，只在非轮腿关节真正越过 URDF 限位后生效。


## 5. 单独扩大 B2 calf backlash 范围

基于 `Jun13_20-10-00_` 的 B2 play 模型已稳定跑到 22k，本次只扩大小腿虚位随机化范围，不改其它 domain randomization，也不改 play 模型形态参数。将 `calf_backlash_range` 从 `[0.005, 0.02]` 提到 `[0.005, 0.03]` rad，上限约从 1.15 度增加到 1.72 度。

建议从 `Jun13_20-10-00_/model_22000.pt` 或 `model_22001.pt` 续训 500-1000 iter。重点观察 `rew_smoothness`、`rew_action_rate`、`rew_torques`、`rew_base_height`、`rew_lin_vel_z`、`rew_dof_pos_limits`、`value_loss` 和 `terrain_level`。若动作代价明显恶化但 value loss 稳定，优先将上限回退到 0.02 或尝试 0.025。
