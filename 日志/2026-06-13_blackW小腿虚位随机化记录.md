# 2026-06-13 blackW 小腿虚位随机化记录

## 1. A 档 calf backlash deadzone 随机化

背景：实机小腿关节不是电机直驱，平行四边形连杆与齿轮/连接件存在较明显虚位；同向持续运动啮合后响应尚可，主要风险来自虚位导致的小幅控制误差和换向初段空行程。完整方向迟滞模型暂不一次引入，先做 A 档保守压力测试。

实现：blackW 运行时识别 4 个 `calf_joint` 索引，并为每个 env、每条小腿在 reset 时采样 `calf_backlash_widths`。在 `_compute_torques` 的 P 控制路径中，仅对小腿 `pos_err` 做对称 deadzone：小于虚位宽度的部分不进入位置力矩，超过后只保留超出量；轮子速度控制、hip/thigh 位置控制和观测不受影响。

配置：新增 `domain_rand.randomize_calf_backlash = True`，`calf_backlash_range = [0.0, 0.035]` rad，约 0 到 2 度。该范围先偏保守，用于验证策略是否能适应小腿传动松旷；若实机虚位更明显，再考虑 `[0.01, 0.06]`。

预期观察：训练中重点看 `rew_tracking_lin_vel_x/y`、`rew_tracking_ang_vel`、`rew_base_height`、`rew_lin_vel_z`、`rew_torques`、`rew_smoothness`、`rew_collision`、`terrain_level` 和 `value_loss`。sim2sim/实机重点看小腿换向、落地、过墙后是否更稳，是否减少因小腿虚位导致的姿态抖动。

风险和回退：A 档 deadzone 不是方向相关 hysteresis，会在同向啮合后仍弱化小误差位置控制，因此可能让小腿显得偏软、落地支撑变差或促使策略加大动作幅度。如果出现 episode length 下降、smoothness/torques 明显恶化或越障退化，优先关闭 `randomize_calf_backlash` 或将范围降到 `[0.0, 0.02]`。若 A 档有效但仍不能解释实机换向空程，再实现 B 档方向迟滞 backlash。


## 2. B 档 calf backlash hysteresis 随机化

基于 `Jun13_14-45-32_` 的 A 档结果，`calf_backlash_range = [0.01, 0.08]` 和 `entropy_coef = 0.005` 从 `Jun12_22-25-45_` 20k 续训到 21k 未出现崩溃：末段 episode length 约 970，terrain level 约 5.3，value loss 正常。但 A 档的 `rew_smoothness`、`rew_action_rate` 和 `rew_torques` 较基线明显变差，说明对称 deadzone 会让小腿在同向啮合后仍显得偏软，策略需要用更大的动作变化吃掉虚位。

本次将 calf 虚位从 A 档对称 deadzone 改为 B 档方向迟滞 hysteresis。实现方式：保留每个 env、每条小腿随机采样的 `calf_backlash_widths`，新增 `calf_backlash_effective_targets`、`calf_backlash_last_targets`、`calf_backlash_remaining` 和 `calf_backlash_dirs`。当 calf target 同向变化时，若没有剩余空程则 effective target 正常跟随；当 target 方向反转时，先将 remaining 设为该关节采样虚位宽度，后续目标变化先消耗 remaining，超过剩余空程的部分才传递到 effective target。最终 P 控制使用 `effective_target - dof_pos` 作为小腿位置误差。

配置：新增 `calf_backlash_mode = "hysteresis"`，B1 范围先设为 `calf_backlash_range = [0.01, 0.06]` rad。保留 `"deadzone"` 兼容模式，便于回到 A 档对照。建议从 `Jun13_14-45-32_/model_21000.pt` 或 `model_21001.pt` 分叉续训，`entropy_coef` 继续用 0.005，不再额外加大。

预期观察：相比 A 档，理想现象是 `rew_smoothness`、`rew_action_rate`、`rew_torques` 有所回落，同时 `mean_episode_length` 维持 950+、terrain level 维持 5 左右、value loss 不抬升。sim2sim/实机重点看小腿换向初段是否更贴近真实空程，同向持续支撑是否比 A 档更硬、更少拍腿。

风险和回退：hysteresis 引入跨 step 状态，若出现小腿 target 与实际姿态长期偏置、落地支撑变慢、过墙后恢复滞后，优先将范围降到 `[0.005, 0.04]` 或切回 `calf_backlash_mode = "deadzone"` 做对照。若 B1 稳定且动作指标改善，再考虑将上限恢复到 0.08。
