# 2026-07-01 black 稳定性抗扰动第一步记录

## 改动目标

沿 `Jul01_03-07-04_` 的干净 Go1-like 基线继续小步增强，目标从复杂越障转向稳定速度跟踪、规整步态和抗扰动能力，为后续背负机械臂训练做准备。

## 主要改动

- 终止逻辑保持不变：`terminate_after_contacts_on = ["base"]`，腿部擦碰不直接终止 episode。
- 地形分布移除上下楼梯、高墙、沟壑和桥，仅保留平地、光滑斜坡、崎岖斜坡与乱石：
  - `terrain_proportions = [0.4, 0.15, 0.15, 0.0, 0.0, 0.3, 0.0, 0.0, 0.0, 0.0]`
- 轻量打开接触惩罚：
  - `collision = -0.05`
- 暂不打开 `feet_stumble`、`foot_slip`、`feet_air_time`、`trot`、`raibert` 等项，避免一次引入过多变量。

## 预期观察

- gait 应保持 `Jul01_03-07-04_` 的干净程度，不应明显变僵硬。
- `Episode/rew_collision` 可以偶发为负，但不应长期成为主要负项。
- `Train/mean_episode_length` 应继续接近 timeout；若明显下降，优先回退 `collision` 到 `-0.0` 或减小到 `-0.02`。
- `terrain_level` 这次不再受楼梯类地形干扰，应更能反映平地/斜坡/乱石通过能力。

## 风险和回退

- `collision` 只按接触 body 计数，不区分轻擦和重撞；如果权重过强，可能导致策略抬腿异常或过度保守。
- 若训练中出现动作僵硬、速度跟踪下降或乱石上不敢迈步，先回退 `collision`，不要同时改 reward 主干。

## 机械臂质心偏移随机化补充

- 将 COM 偏移随机化从统一三轴范围扩展为可按轴配置，旧字段 `com_displacement_range` 仍作为未配置轴的 fallback。
- `black` 当前设置：
  - `com_displacement_range_x = [-0.08, 0.08]`
  - `com_displacement_range_y = [-0.02, 0.02]`
  - `com_displacement_range_z = [-0.05, 0.05]`
- 目的：机械臂背负后主要影响机体前后向重心，先增强 x 轴鲁棒性，同时收窄 y 轴随机化，避免为较小的侧向误差过度牺牲规整步态。
- 观察重点：若策略出现持续前后俯仰、站立高度不稳或加减速抖动，可先缩小 x 轴范围到 `[-0.06, 0.06]`；若实机侧向稳定性不足，再逐步扩大 y 轴范围。
- 修复：分轴配置允许不再保留旧的统一 `com_displacement_range` 字段；未配置某个轴时，先回退到旧统一字段，若也不存在则该轴默认 `[0.0, 0.0]`。

## Jul01_16-55-53_ 尖峰回退

- 现象：续训 `Jul01_16-55-53_` 出现剧烈尖峰，`Train/mean_reward` 在 iter 2134 降到约 `-257.5`，`Loss/value_function` 在 iter 2210 升到约 `1681`。
- 定位：尖峰主要对应 `rew_base_height` 与 `rew_lin_vel_z` 的异常，`rew_collision` 全程很小，不是主因。
- 判断：该 run 在续训时同时加重了 `base_height`、`orientation`、`action_rate`、`torques`，并扩大了速度课程与扰动范围，reward 尺度变化过大导致 critic/value loss 被异常 return 拉爆。
- 回退策略：只保留地形分布、轻量 `collision` 与 COM 分轴随机化，其他尖峰相关项回到 `Jul01_03-07-04_` 附近：
  - `max_curriculum = 2.0`
  - `disturbance_range = [-30.0, 30.0]`
  - `orientation = -0.2`
  - `base_height = -1.0`
  - `action_rate = -0.01`
  - `smoothness = -0.01`
  - `torques = -0.0`
  - `com_displacement_range_y = [-0.02, 0.02]`
- 下一版观察重点：确认 reward 尺度稳定后，再单独小步增强姿态、高度或动作正则，不要同时打开多个强约束。

## Terrain Probe 直线环境

- 背景：`Jul01_17-32-14_` reward 和 episode length 稳定，但 `terrain_level` 仍长期低位。原因是 terrain curriculum 按 episode 结束时相对出生点的净位移升级，随机 y/yaw 命令与 10s 重采样会抵消净位移。
- 方案：模仿 `blackW` 固定 env 子集的命令采样思路，为 `black` 增加小比例 terrain probe env。
- 当前设置：
  - `terrain_probe.enabled = True`
  - `terrain_probe.env_fraction = 0.10`
  - `terrain_probe.per_terrain_type = True`
  - `terrain_probe.lin_vel_x = 0.8`
  - `terrain_probe.lin_vel_y = 0.0`
  - `terrain_probe.ang_vel_yaw = 0.0`
- 实现：每次 `_resample_commands` 后，对每个 terrain column 内前 10% env 强制覆盖为正 x 直线命令，其余 env 保持原随机命令分布。
- 预期：probe env 提供稳定的净前进样本来推动 terrain level；主训练分布仍由 90% 随机命令 env 维持。
- 风险：若直线 probe 比例过大，会让策略更偏前进；若 `terrain_level` 仍不上升，再考虑提高 probe 速度或比例，而不是先改 reward。

## 静止站立力矩平衡奖励

- 新增 `stand_torque_balance`，只在静止命令下生效：
  - `norm(commands[:2]) < 0.10`
  - `abs(commands[2]) < 0.10`
- 目标：站立时鼓励左右对称电机力矩幅值更平衡，减少单侧腿长期承担过大支撑力，为后续背负机械臂时的静态稳定性做准备。
- 实现：比较左右镜像关节的归一化力矩幅值 `abs(torque / torque_limit)`，不直接比较带符号力矩，避免左右关节轴方向不同导致误判。
- 当前配对：
  - `FL/FR`、`RL/RR` 的 hip、thigh、calf 三组左右对称关节。
- 当前权重：
  - `stand_torque_balance = -0.05`
- 观察重点：看 `Episode/rew_stand_torque_balance` 是否只在静止样本中产生小幅负项；若导致站立动作僵硬或影响起步，可先回退到 `0.0` 或降到 `-0.02`。

## Jul01_20-45-11_ 地形等级复查

- 训练来源：从 `Jul01_17-32-14_` resume 到 4000 iter。
- 日志表现：
  - `Train/mean_reward`: 3000 iter 的 `1.27` 恢复到 3999 iter 的 `28.64`。
  - `Train/mean_episode_length`: 3000 iter 的 `52.48` 恢复到 3999 iter 的 `958.61`。
  - `Episode/terrain_level`: 3000 iter 的 `2.49` 下降并稳定在约 `1.3`，最终 `1.24`。
- 判断：策略训练过程稳定，问题不是 reward 崩坏；`terrain_level` 低主要来自 curriculum 升级样本不足，以及 play 中离散障碍地形通过率差。
- 配置细节：当前 `terrain_proportions = [0.2, 0.3, 0.3, 0.0, 0.0, 0.2, ...]`，最后的 `0.2` 落在第 5 类 `discrete_obstacles_terrain`，也就是当前 play 卡住的“乱石/离散障碍”地形。
- 修正：原 terrain probe 使用全局前 10% env id。由于 `terrain_types` 按 env id 连续分配，前 10% env 实际只覆盖前两个 flat terrain column，不能帮助斜坡和乱石升级。现改为每个 terrain column 内各取 `env_fraction` 的 probe env，使 flat、斜坡、rough slope、离散障碍都有直线前进样本。
- 下一版观察重点：
  - `Episode/terrain_level` 是否不再从初始等级快速掉到 1.3 以下。
  - play 中离散障碍是否仍卡住；若仍卡住，下一步优先弱化离散障碍高度/密度或对该地形使用更低 probe 速度，而不是继续加稳定性惩罚。

## 步态规整第一步

- 观察问题：
  - 进入策略控制后前腿落点偏后，身体略微前倾。
  - 摆动脚抬腿不足，接近贴地磨蹭。
  - 髋/足端略向内收。
  - yaw 指令下腿向外伸展不足，转向步态显得局促。
- 改动目标：只加轻量 gait shaping，不改变地形、扰动、终止条件。
- 当前改动：
  - `clearance_height_target: 0.06 -> 0.09`，恢复到更接近 base/Go1 的抬脚高度。
  - `raibert` 小权重打开为 `0.08`，用于引导摆动后期落脚点。
  - `raibert.nominal_front_x: 0.21 -> 0.23`，轻微把前腿名义落点前移。
  - `raibert.nominal_y: 0.155 -> 0.17`，给足端更宽的名义站距。
  - `raibert.max_linear_offset_y: 0.06 -> 0.08`，增加侧向速度指令下的落脚空间。
  - `raibert.max_yaw_offset: 0.10 -> 0.12`，增加 yaw 指令下的外摆目标。
  - `feet_spacing` 小权重打开为 `-0.08`，防止脚端长期向中线收窄。
- 暂不改动：
  - `hip_pos = -0.5` 保持不变；该项在侧移/yaw 指令下已有降权，避免限制转向外摆。
  - `trot`、`feet_air_time` 继续关闭，先不强行规定接触时序，避免把干净步态重新拉散。
- 观察重点：
  - play 中摆动脚是否明显离地但不过度高抬。
  - 前脚触地点是否回到肩部前后更自然的位置，pitch 是否减小。
  - yaw 指令下足端是否能打开；若出现外八/劈叉倾向，优先把 `raibert.max_yaw_offset` 回到 `0.10` 或关闭 `feet_spacing`。
