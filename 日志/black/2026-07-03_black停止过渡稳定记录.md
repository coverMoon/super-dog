# 2026-07-03 black 停止过渡稳定记录

## 运动到停止过渡

- sim2real 现象：从运动指令切到停止时姿态不够稳。
- 约束：`orientation` 不回退，继续保持当前较强姿态约束。
- 判断：固定静止 `stand_probe` 只训练从一开始就站立的样本，不能充分覆盖“带速度运动中突然给零命令”的刹停过渡。
- 新增 `commands.stop_probe`：
  - `enabled = True`
  - `env_fraction = 0.05`
  - `per_terrain_type = True`
  - `cycle_time = 6.0`
  - `move_time = 3.0`
  - `lin_vel_x = 0.8`
  - `lin_vel_y = 0.0`
  - `ang_vel_yaw = 0.0`
- 实现：在每个 terrain column 内避开 terrain probe 和 stand probe 后，再取约 5% env。该子集每 6 秒循环一次：前 3 秒按固定前进命令运动，后 3 秒命令归零站稳。
- 预期：让策略在 batch 中稳定看到“当前仍有机身速度，但命令已经为 0”的状态，利用 tracking、stand_still、力矩/足端受力平衡等现有奖励学习刹停。
- 观察重点：
  - sim2real 从前进切停止时是否减少点脚、甩身和二次调整。
  - `Episode/rew_stand_still`、`rew_stand_torque_balance`、`rew_stand_feet_force_balance` 是否保持可见量级。
  - 若 terrain level 被拖低，优先把 `stop_probe.env_fraction` 降到 `0.03`；若刹停仍不稳，再考虑增加 `move_time` 或加入 yaw-to-stop 样本。
