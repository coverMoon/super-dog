# 2026-07-02 black 站立足端受力平衡记录

## 静止站立足端受力平衡

- 背景：已有 `stand_torque_balance` 用于静止站立时约束左右对称电机力矩幅值平衡；为了进一步让站立时左右侧实际承重更均衡，新增足端受力平衡奖励。
- 新增奖励：`stand_feet_force_balance`，只在静止命令下生效：
  - `norm(commands[:2]) < 0.10`
  - `abs(commands[2]) < 0.10`
- 默认配置：
  - `axis = "z"`
  - `pairs = [("FL", "FR"), ("RL", "RR")]`
  - `min_pair_force = 5.0`
  - `stand_feet_force_balance = -0.1`
- 实现：逐对比较左右镜像足端 z 轴接触力，使用 `(left_z - right_z) / pair_total_z` 的平方作为归一化惩罚，避免 payload 质量变化后奖励尺度随总重量漂移，也避免前后脚互相补偿掩盖单脚卸载。
- 选择 z 轴而非全 3D 力的原因：
  - z 轴接触力主要对应垂向支撑/承重分配，最贴近“左右站立受力平衡”的目标。
  - x/y 接触力主要是摩擦与剪切力，会受到坡面、扰动恢复、轻微滑移和 yaw 调整影响；若强行左右平衡全 3D 力，可能惩罚必要的抗扰动作。
  - 若后续需要做平地静态校准实验，可临时把 `axis` 改为 `"xyz"` 对比，但常规训练默认保持 `"z"` 更稳。
- 风险与观察：
  - 若权重过大，可能让策略为了左右承重平衡牺牲自然姿态恢复；先用 `-0.1` 小权重观察。
  - 重点看 `Episode/rew_stand_feet_force_balance` 是否只在静止样本中产生小幅负项，以及 play 中站立是否减少单侧压腿。

## 对称足端逐对修正

- 修正原因：左右侧总和会允许 `FL` 轻抬、`RL` 多承重这种前后补偿，无法约束单个镜像足端对的受力对称。
- 当前实现改为 `FL-FR`、`RL-RR` 逐对比较，逻辑与 `stand_torque_balance` 的对称电机逐对比较保持一致。

## 固定静止 Stand Probe

- 背景：`stand_torque_balance` 和 `stand_feet_force_balance` 在日志中量级很小，主要原因是随机连续命令下真正满足静止阈值的样本比例很低，而不是奖励方向无效。
- 新增 `commands.stand_probe`：
  - `enabled = True`
  - `env_fraction = 0.05`
  - `per_terrain_type = True`
  - `lin_vel_x = 0.0`
  - `lin_vel_y = 0.0`
  - `ang_vel_yaw = 0.0`
- 实现：每次 `_resample_commands` 后，先保留 terrain probe 的直线样本，再在每个 terrain column 内紧接着取 5% env 覆盖成零速度静止命令，避免与 terrain probe 重叠。
- 预期：稳定提供静止站立训练样本，让力矩平衡、足端受力平衡和 `stand_still` 有足够 batch 占比。
- 观察重点：
  - `Episode/rew_stand_torque_balance` 和 `Episode/rew_stand_feet_force_balance` 是否从接近 0 提高到可观测的小负项。
  - sim2sim 静止时前脚轻点地是否减少。
  - 若静止过僵或影响起步，优先降低 `stand_probe.env_fraction` 到 `0.03`，而不是先关掉奖励。

## Yaw 指令转向步态修正

- sim2real 现象：yaw 指令下腿抬不起来，足端向外伸展不足，导致旋转姿态不稳。
- 判断：
  - 当前 `foot_clearance` 对 yaw 有效，但目标高度是固定值，没有随 yaw 指令增大而提高。
  - `raibert.max_yaw_offset = 0.12` 对真实机器人转向外摆偏保守。
  - `orientation = -0.8` 在转向时可能过度压制自然姿态调整，使腿部不敢外摆。
- 改动：
  - `orientation: -0.8 -> -0.2`
  - `raibert.max_yaw_offset: 0.12 -> 0.16`
  - 新增 yaw 专用抬脚裕量：
    - `yaw_clearance_gain = 0.05`
    - `max_yaw_extra_clearance = 0.05`
- 实现：在 `_reward_foot_clearance` 中根据 `abs(commands[:, 2]) / max_ang_vel_yaw` 增加摆动相目标高度，最大额外 5cm；直行和静止基本不受影响。
- 观察重点：
  - yaw 原地转向时脚是否明显离地，减少拖地。
  - 足端是否能向外打开，身体是否不再因腿局促而晃动。
  - 若出现转向步幅过大或外摆过猛，优先把 `raibert.max_yaw_offset` 回到 `0.14`，不要先降低 yaw 抬脚裕量。
