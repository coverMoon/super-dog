# 2026-06-20 blackW 上楼梯前倾关节回中约束记录

## 1. 上楼梯前倾时增加定向关节回中

现象：Jun19_14-46-46_ 上楼梯效果有所改善，但前轮触到台阶后尚未抬起时，机身可能继续形成较大前倾；即使随后前向速度已接近零，关节仍会维持偏离默认姿态，实机稳定性不足。直接增大全局 `run_still` 会同时影响平地行进和前腿起抬，因此本次保留 `run_still = -1.0` 不变，新增 `difficult_posture_hold`。

新奖励只在上楼梯 type 3、正向 x 指令大于 0.2、y/yaw 指令较小时启用。以 `projected_gravity[:, 0]` 的前倾分量做软门控：0.08 以下不触发，0.08 到 0.20 之间逐渐增强。仅惩罚 thigh/calf 偏离默认角度超过 0.1 rad 的部分，不重复约束 hip。前轮 lift timer active 时，对应前腿权重降为 0.3，给触障起抬保留动作空间；后腿仍保持完整回中约束，减少支撑链持续把机身顶向前方。初始 scale 为 -0.3。

预期观察：上楼梯触障停住后最大前倾减小，关节能更快回到稳定支撑姿态，同时前腿起抬延迟和楼梯通过率不恶化。TensorBoard 关注 `rew_difficult_posture_hold`、`rew_run_still`、`rew_wheel_obstacle_lift`、`rew_orientation`、`rew_progress`、`rew_torques`、`rew_smoothness` 和 `terrain_level`。

风险与回退：若前腿起抬变慢，优先将 `front_lift_scale` 从 0.3 降到 0 或增大 `joint_margin`；若正常爬楼动作变硬，降低 scale 到 -0.15 或提高 `pitch_start`；若前倾方向门控与仿真姿态符号相反，将 `forward_pitch_sign` 改为 -1.0。建议从 Jun19_14-46-46_/model_41000.pt 分叉短训 500 到 1000 iter 后先做固定楼梯 sim2sim 对照。

验证：已运行 `python -m py_compile legged_gym/legged_gym/envs/blackW/blackW_config.py legged_gym/legged_gym/envs/blackW/blackW_env.py`，语法检查通过。


## 2. Jun20_15-03-04_ 量级分析与增强

结果：该 run 从 model_41000.pt 续训到 42000。difficult_posture_hold 在 1000 个 iteration 中有 985 个 iteration 记录到非零值，但全程均值仅约 -0.000154，末 500 iter 约 -0.000163，单次 iteration 最低约 -0.00107；相比同期 rew_run_still 约 -0.0374，仅为其约 0.44%。说明奖励并非完全没有触发，而是 type 3、纯 x 指令、零起点 pitch ramp、0.1 rad 关节死区和前腿 0.3 权重叠乘后量级过薄。

训练整体未失稳：相对 Jun19 末段，mean_reward 约 72.02 提到 72.47，mean_episode_length 约 974.5 提到 977.4，terrain_level 基本不变，rew_progress 和 rew_wheel_obstacle_lift 略有改善；但 rew_orientation 从约 -0.1831 变为 -0.1877，未显示前倾姿态已经得到有效改善。

后续调整：joint_margin 从 0.1 降到 0.05；新增 pitch_min_scale = 0.25，使上楼梯满足指令门控时始终保留 25% 的基础关节回中强度，并在 forward pitch 从 0.08 增至 0.20 时平滑增强到 100%；difficult_posture_hold scale 从 -0.3 提到 -0.6。front_lift_scale 仍保持 0.3，避免额外约束阻碍前腿触障起抬。

预期观察：rew_difficult_posture_hold 应从 1e-4 量级提升到至少 1e-3，并更接近 -0.002 到 -0.01 的可观察区间。若仍小于 -0.001，优先放宽 y/yaw 指令硬门控，而不是继续单独放大 scale；若前腿起抬变慢或楼梯动作变硬，优先将 scale 回退到 -0.3 或把 pitch_min_scale 降到 0.1。
