# 2026-07-01 blackW 楼梯后腿强化续训配置记录

## 1. 恢复 Jun30_17-09-17_ A 组参数

根据 6/30 训练对照，`Jun30_17-09-17_` 的 A 组比 `Jun30_17-11-25_` 的 B 组训练侧更干净：pair escape 信号更强，`mean_reward`、`mean_episode_length`、`rew_progress` 更好，且 B 组 target 到达增强带来了更重的 `dof_pos_limits` 和末段 value loss 风险。因此当前配置先恢复为 A 组参数，继续用于后续 sim2sim/sim2real 观察或续训。

关键参数：`load_run = Jun30_13-38-24_`、`max_iterations = 1000`、`stairs_pair_escape = 1.5`、`front_pair_weight = 0.7`、`rear_pair_weight = 2.8`、`progress_weight = 0.55`、`rear_lift_target_offset = 0.02`、`over_lift_penalty_weight = 0.12`。继续关闭 `stairs_rear_target_bonus = 0.0` 和 `stairs_rear_stuck_escape = 0.0`。

观察重点：后腿卡住等待时间是否比 `Jun30_13-38-24_` 缩短，前腿是否保持稳定，`rew_stairs_pair_escape` 是否保持在可见量级，同时关注 `dof_pos_limits`、`foot_impact_vel`、`torques` 是否随更强 pair 脱困奖励变重。

## 2. A 组实机前倾反馈与下一步方向

实机测试反馈：当前 A 组整体效果还可以，说明从 `Jun30_13-38-24_` 继续并增强 `stairs_pair_escape = 1.5` 的方向没有明显破坏楼梯通过能力；但又出现了一点此前见过的上楼梯前倾感。这个现象需要和 6/20、6/21 的前倾/回中实验联系起来看：当时 `difficult_posture_hold` 触发量级太小，而更直接的 `run_still = -3` 或楼梯分层 `stairs_run_still` 对抑制关节偏移更有效，但风险是可能压住前腿起抬或让动作变硬。

当前代码里只保留全局 `run_still = -1.0`，没有启用单独的 `stairs_run_still`；同时 A 组把 pair 脱困信号显著放大，可能让机器人在前/后轮抵台阶沿时更积极给腿部动作，但姿态回中没有同步增强，因此前倾感重新显现。由于 A 组实机已经可用，不建议马上大改 lift 高度或继续加后腿 offset。

下一步若要处理前倾，优先考虑两种小步方案：一是恢复一个很轻的楼梯局部回中项，例如只在上楼梯 type 3、x 前进且 y/yaw 较小时增加 `stairs_run_still = -0.5 ~ -1.0`，避免直接把全局 `run_still` 从 -1 加大；二是略微降低 pair escape 激进程度，例如 `stairs_pair_escape = 1.3~1.4` 或 `rear_pair_weight = 2.6`，验证前倾是否来自脱困奖励驱动过强。若前倾只是轻微且通过能力明显改善，应先保留 A 组做更多 sim2real 观察。

## 3. A 组基础上的轻量回中与 orientation 衰减增强

在 A 组实机表现可接受但出现轻微前倾感后，当前不回退到 6/22 那套较强 `run_still/stairs_run_still` 行为配置，也不继续加高后腿 target。改为小步增强：保留全局 `run_still = -1.0`，新增轻量 `stairs_run_still = -0.5`，只在上楼梯 type 3、x 前进且 y/yaw 较小时叠加非轮关节回中。这样楼梯上等效回中从 -1.0 增至 -1.5，低于此前强回中路线的 -3，目标是减轻前倾但尽量不压住前后腿起抬。

同时进一步增强 `orientation` 的地形自适应衰减：`orientation_terrain_sigma` 从 0.0015 降到 0.0010，`orientation_terrain_min_scale` 从 0.05 降到 0.03。当前 orientation reward 中 roll 仍完整惩罚，pitch 会随地形高度波动衰减；这次改动让楼梯/复杂接触下的 pitch 惩罚更快降低，减少姿态项和越障抬腿/贴障滚越的冲突。

观察重点：`rew_stairs_run_still` 是否达到可见但不过大的量级，前倾是否减轻；同时看前腿/后腿起抬是否变慢、`rew_progress` 和 `rew_wheel_obstacle_lift` 是否下降，以及 `orientation` 衰减后是否出现 roll/pitch 姿态过松。若动作变硬或后腿又抬不起来，优先把 `stairs_run_still` 降到 -0.25 或关闭，而不是继续改 lift reward。
