## 1. Jun10_18-21-18_ 后期异常观察

Jun10_18-21-18_ 从约 19000 继续训练到 19400+，曲线仍不稳定：19150 后 value_loss 多次升到千级，mean_reward 出现大幅负脉冲，base_height、lin_vel_z、torques、collision 和 smoothness 也有明显异常。对比 Jun09_23-04-32_ 同步段，后者在 19200 后 value_loss 基本恢复到低位，而 Jun10 run 到 19400+ 仍未恢复，判断该分叉不宜继续作为主线。

## 2. wheel_obstacle_lift 回退到非 rollover 版本

根据 Jun10 异常和前一轮对 rollover_distance 的怀疑，本次将 wheel_obstacle_lift 回退到不使用 rollover_distance 的版本：删除 wheel_obstacle_lift_start_forward_pos buffer、触发时的 forward_pos 记录、rollover_progress / rollover_scale 调制，以及 config 中 rollover_distance / rollover_base / rollover_weight 参数。lift_reward 恢复为 progress_weight * lift_progress + (1 - progress_weight) * target_reward - over_lift_penalty。

同时将 wheel_obstacle_lift 相关参数退回仓库当前基线：high_obstacle_height_threshold = 0.18、over_lift_margin = 0.02、wheel_obstacle_lift scale = 1.5。目的是先回到 rollover 前更稳定的奖励形态，避免继续把高墙接触过程推向 critic 爆点、高 torque 和碰撞。

建议后续从明确可用点分叉，不使用 load_run=-1 自动续最近 run；优先显式指定 Jun09_23-04-32_ / checkpoint 19000 或更稳的 Jun09_20-18-11_ / checkpoint 19000。观察重点：value_loss 是否保持低位，wheel_obstacle_spin、torques、collision 是否回落，以及低速高墙 sim2sim 是否仍有通过能力。
